## 🚀 简介

**Interview Prep Generator** 是一个 Agent Skill，适用于任何支持 Web 搜索、文件读写和代码执行的 AI Agent 平台（如 TRAE、Claude Code、Cursor 等）。专为求职者设计，提供两大核心功能：

1. **复习资料生成**：根据职位描述（JD）和个人简历，自动生成定制化的笔试和面试复习资料
2. **面试记录整理**：通过面试录音/备忘录，整理结构化面试记录，补充标准答案，扩展相关 Q&A，生成个性化复习计划

### 解决什么问题？

求职时你可能会遇到这些问题：
- 😫 网上的面经零散不系统，不知道哪些是重点
- 🤔 自己的简历经历和 JD 要求如何匹配？
- 📚 网上的答案质量参差不齐，不知道哪个是对的
- 🎨 想要一份美观、可打印、可搜索的复习资料
- 🎙️ 面试完了记不清问了什么、自己怎么答的、哪里答得不好

**Interview Prep Generator** 一次解决所有这些问题。

## ✨ 核心能力

### 功能一：复习资料生成

#### 1. 🔍 全网信息采集
- **公司背景**：业务方向、技术文化、近期动态、融资状态
- **面经搜索**：牛客网、知乎、CSDN、脉脉等多平台面经
- **笔试信息**：题型、难度、时长、笔试平台
- **薪资数据**：校招薪资范围（白菜/普通/SP档）、福利待遇
- **面试流程**：面试轮次、各面侧重点、面试官风格

#### 2. 📝 智能题目生成
- **笔试题**：编程语言核心、计算机基础、数据库、算法编程题、岗位专项
- **面试题**：项目深挖（STAR框架）、技术深度问答、系统设计、场景题、行为面试
- **差异化设计**：避免与已有资料重复，突出岗位独特考察点

#### 3. ✅ 标准答案
- 技术内容准确可核实
- 关键得分点高亮标注
- 代码示例可运行
- 来源引用标注
- 简历关联提示

### 功能二：面试记录整理

#### 1. 🎙️ 录音/笔记解析
- 支持面试录音转写文本（通过 Whisper 等工具）
- 支持手写笔记/备忘录文本
- 自动识别面试官问题和候选人回答
- 标注问题类型和回答质量

#### 2. 📋 结构化面试记录
- 按时间顺序还原完整面试过程
- 每个问题标注类型（技术/项目/设计/行为）
- 回答质量评级：✅优秀 / ⚠️一般 / ❌不足 / ⏭️未回答

#### 3. ✅ 标准答案补全
- 为回答不足的问题补充标准答案
- 关键得分点分析
- 改进建议："如果重来，怎么回答更好？"

#### 4. 🔄 延伸 Q&A 扩展
- 基于每个面试问题扩展 2-3 个相关追问
- 预测面试官可能继续深挖的方向
- 为下一轮面试做准备

#### 5. 📊 个性化复习计划
- 薄弱点总结：哪些知识点需要重点复习
- 复习行动计划：基于面试表现生成

## 🏁 快速开始

### 前置条件

- 任何支持 Web 搜索 + 文件读写 + 代码执行的 AI Agent 平台
- Google Chrome（用于 HTML 转 PDF，可选）

将 `interview-prep` 文件夹放入你项目的 skills 目录：

```bash
# 通用结构

├── .agent/skills/       # 或 .trae/skills/ 等，取决于你的 Agent 平台
│   └── interview-prep/
│       ├── SKILL.md
│       ├── README.md
│       ├── template.html
│       ├── tools/
│       │   └── html2pdf.py
│       └── LICENSE
```

岗位：后端开发工程师

## 🛠️ 配套工具

工具统一放在 `tools/` 目录下，方便后续维护和新增。

### html2pdf.py — HTML 转 PDF

将生成的 HTML 复习资料转为高质量 PDF，方便手机随时查看。

#### 使用方法

```bash
# 转换单个文件
python3 tools/html2pdf.py 面经/xxx笔试面试复习资料.html

# 转换所有 HTML（自动扫描当前目录）
cd 面经 && python3 ../tools/html2pdf.py

# 超清模式（3倍 DPI，文件更大但更清晰）
python3 tools/html2pdf.py --dpi=3 xxx.html

# 批量转换
python3 tools/html2pdf.py a.html b.html c.html
```

#### 核心优化

| 优化项 | 说明 |
|--------|------|
| 自动展开折叠卡片 | 注入 CSS 强制所有 Q&A 答案在 PDF 中可见 |
| 强制打印背景色 | 保留渐变色、标签色、表格底色 |
| 高 DPI 渲染 | 默认 2x Retina 清晰度，支持 3x 超清 |
| 容错设计 | 即使 Chrome 超时，PDF 已生成则判定成功 |

#### 前置条件

- macOS / Linux / Windows
- Google Chrome 或 Chromium 内核浏览器（Edge、Brave 等）

## 🎙️ 语音转写工具链

面试记录整理模式（Workflow B）支持音频输入。当用户提供面试录音文件时，需要先进行语音转文字（Speech-to-Text），再进入后续整理流程。

### 推荐转写方案

| 方案 | 类型 | 说明 | 安装/使用 |
|------|------|------|-----------|
| **OpenAI Whisper** | 本地开源 | 多语言支持、免费、隐私友好 | `pip install openai-whisper` |
| **faster-whisper** | 本地开源 | Whisper 加速版，速度快 4x | `pip install faster-whisper` |
| **飞书妙记** | 在线 | 中文效果好，需飞书账号 | 上传音频到飞书妙记，导出逐字稿 |
| **通义听悟** | 在线 | 阿里出品，免费额度 | tingwu.aliyun.com |

### Whisper 快速上手

```bash
# 安装（需要 Python 3.9+ 和 ffmpeg）
pip install openai-whisper

# 转写（中文面试录音）
whisper interview.mp3 --language zh --model medium --output_format txt

# 模型选择建议
# base    (~300MB)  速度最快，精度一般，适合快速预览
# small   (~1GB)    速度较快，精度尚可
# medium  (~3GB)    推荐，精度好，需约 3GB 显存
# large   (~3GB+)   精度最高，速度最慢
```

### 转写后的处理流程

```
面试录音 (mp3/wav/m4a)
    │
    ▼
 语音转文字 (Whisper / 飞书妙记 / 通义听悟)
    │
    ▼
 转写文本 (txt)
    │
    ▼ 用户提供给 Agent
    │
    ▼
 面试记录整理模式 (Phase B1-B5)
    │
    ▼
 结构化面试记录 HTML
```

> **注意**：转写文本可能有人名、技术术语识别错误，Agent 在整理过程中会尝试根据上下文修正，但仍建议用户人工校对关键内容。

</details>

<details>
<summary><strong>Q: 支持哪些 Agent 平台？</strong></summary>

</details>

<details>
<summary><strong>Q: 支持哪些岗位？</strong></summary>

支持所有技术类岗位，包括但不限于：后端开发、前端开发、DevOps/SRE、算法工程师、客户端开发、数据分析等。对中文互联网校招场景优化最佳。
</details>

<details>
<summary><strong>Q: 简历需要什么格式？</strong></summary>

支持 HTML、PDF、Markdown、纯文本格式。如果提供文件路径，Skill 会自动读取。也可以直接在对话中粘贴简历内容。
</details>

<details>
<summary><strong>Q: 面试录音支持什么格式？</strong></summary>

支持任意音频格式（mp3/wav/m4a 等），需先通过转写工具（如 Whisper、飞书妙记等）转为文本。也可以直接提供面试时的手写笔记或备忘录文本。
</details>

<details>
<summary><strong>Q: 多份复习资料会重复吗？</strong></summary>

Skill 内置差异化机制（Phase 6），会避免与用户已有资料重复相同的基础题，突出每个岗位独特的考察重点。
</details>

<details>
<summary><strong>Q: 需要联网吗？</strong></summary>

是的，Phase 1 的全网搜索需要 Web 搜索能力。如果离线使用，会跳过搜索环节，仅基于 AI 知识生成内容（质量会降低）。
</details>
